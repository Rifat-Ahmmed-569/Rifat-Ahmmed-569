## THE WAY I BUILD

I like getting close to the problem.

Understanding why a sensor behaves differently than expected. Finding the bug hiding somewhere between hardware and software. Making a robot follow a line consistently. Getting a communication system to work outside the lab.

Sometimes the process is frustrating. That's also where I enjoy it most.

I don't want to just use technology. I want to understand how it works, build with it, and make it work reliably.
